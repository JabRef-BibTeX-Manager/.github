## JabRef Highlights

- **.bib Is The Database:** JabRef BibTeX manager edits records in a file that pdfLaTeX already knows, sitting next to a paper you compile.
- **Keys You Choose:** JabRef citation key stays stable so `\cite{smith2021}` in a document you own does not break after a tidy.
- **Groups For A Project:** JabRef reference library can split a thesis .bib into chapters you actually write.
- **Import From Sources You Query:** JabRef bibliography accepts DOI or database pulls you are allowed to run, then you keep the record locally.
- **Not A Knowledge Organizer With Tasks:** Citavi-style quotations and project plans are another product. This seat is the BibTeX file.

## What Is JabRef

JabRef is a Windows (and multi-platform) reference manager built around BibTeX and BibLaTeX. Authors who already compile with WinEdt, TeXworks, or Overleaf-style source still want a desktop editor for the `.bib`. JabRef BibTeX manager is that editor. JabRef citation key is the identifier the source uses. JabRef reference library is the grouped list. JabRef bibliography is the file you commit beside the `.tex`.

Biblioscape and Citavi store richer notes and Word workflows. Publish or Perish counts citations. JabRef’s culture is keys, fields, and a clean file that a compiler consumes. Duplicate detection matters because two keys for one paper wreck a thesis you own.

Keep libraries for papers you write or were hired to edit. Import only records you have the right to store. Do not paste an entire publisher dump you are not licensed to redistribute.

## Starting with JabRef

Prerequisites: A PC you administer, a TeX project you compile, and references you are allowed to store.

1. **Prepare:** Open the `.bib` beside the `.tex` you already compile, or create one for that title.
2. **Configure:** Set JabRef citation key pattern so new records match the style in that source.
3. **Test:** Add one DOI you have the right to use, then compile a cite in the paper you own.
4. **Refine:** Deduplicate JabRef reference library and file PDFs only where the license allows.
5. **Apply:** Work the rest of JabRef bibliography as chapters grow.
6. **Maintain:** Commit the `.bib` with the TeX tree, and keep a backup before a journal deadline.

## Best Uses

- **Thesis You Compile:** JabRef BibTeX manager next to chapter includes.
- **Article With A Journal .bst You Were Sent:** Keys in JabRef citation key matching that style.
- **Hired Technical Edit:** Only the library the author delivered.
- **Shared Lab .bib You Administer:** Groups per project the lab already owns.
- **Not A Word Knowledge Base:** Use Citavi if the job is quotations in Word.
- **Not An H-Index Query:** Use Publish or Perish.
- **DOI First, Manual Fields Second:** JabRef bibliography stays cleaner.
